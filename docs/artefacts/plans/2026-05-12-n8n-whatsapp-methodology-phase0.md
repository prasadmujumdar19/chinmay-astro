## Token & Context Discipline

### Rule 1 — Word-count gate before reading any file

Before reading any file, check its size:

    wc -c <file>   # bytes
    wc -w <file>   # words

Thresholds:
- Under ~1,500 words → read directly
- 1,500–5,000 words → grep for relevant sections only
- Over 5,000 words → STOP. Write a script to extract and summarise to disk first.

### Rule 2 — Script to disk, grep into context

Never let a large tool call or command dump its full output into the session. Instead:
1. Write a Python or bash script that processes the data and writes a summary to `/tmp/claude-scratch/output.txt`
2. Run it via Bash tool
3. Check word count of the output file
4. Only grep or Read the specific lines you need

    python3 /tmp/claude-scratch/my_analysis.py > /tmp/claude-scratch/result.txt
    wc -w /tmp/claude-scratch/result.txt
    grep -E "(ERROR|MISSING|DISABLED)" /tmp/claude-scratch/result.txt

### Rule 3 — HTML/rich files: strip first

Never read raw HTML, notebook, or JSON dump directly. Convert first:

    python3 -c "
    import re
    html = open('file.html').read()
    html = re.sub(r'<script.*?</script>', '', html, flags=re.DOTALL)
    html = re.sub(r'<style.*?</style>', '', html, flags=re.DOTALL)
    html = re.sub(r'<[^>]+>', ' ', html)
    lines = [l.strip() for l in html.splitlines() if l.strip()]
    open('/tmp/claude-scratch/stripped.txt','w').write('\n'.join(lines))
    " && wc -w /tmp/claude-scratch/stripped.txt

Then grep the stripped file — only read the full file if under threshold.

### Rule 4 — MCP tools: targeted only, never bulk

MCP tool responses land directly in context and cannot be intercepted.
- Always pass specific IDs, filters, and limit parameters
- Never call an MCP tool in a loop — write a bash script instead
- If a search tool (e.g. mnemo) returns a session pointer but not content, do 2–3 targeted keyword searches max before switching to a script approach

### Rule 5 — Large data: automatically script to disk

If you estimate a data pull would exceed ~3,000 words of context, automatically write a script to extract and summarise it to `/tmp/claude-scratch/` instead. This is an internal efficiency technique — no user confirmation needed. Tell the user what you're doing in one sentence, then proceed.

### General

- Surgical Bash commands only — non-surgical output redirects to `/tmp/claude-scratch/`
- Context >60%: `/compact` immediately
- Starting unrelated work after task complete: `/clear`
- Never summarize large tool outputs inline — extract only the fields needed

### Cleanup

Before ending any session, delete scratch files:

    rm -rf /tmp/claude-scratch/

## Session Handoff

- When context approaches 70%, invoke the `handoff` skill
- Handoff file: `.methodology/handoff-<descriptive-slug>.md`
- Content: stopping point, next action, blockers, changed reference values only
- Git history covers what was done. workflow-registry.md covers project state. Only what's NEXT goes in the handoff.

cat > scripts/session-startup.sh << 'EOF'
#!/bin/bash
# Checks n8n reachability via SSH tunnel.
# Reads VPS_SSH_HOST and VPS_TUNNEL_PORTS from .env in current project root.
# Usage: ./scripts/session-startup.sh [project-root]

PROJECT_ROOT="${1:-$(pwd)}"
N8N_LOCAL="http://localhost:5678"

# Load .env
if [ -f "$PROJECT_ROOT/.env" ]; then
  set -a; source "$PROJECT_ROOT/.env"; set +a
elif [ -f "$HOME/.claude/.env" ]; then
  set -a; source "$HOME/.claude/.env"; set +a
fi

# Check n8n reachability
if curl -sf --max-time 3 "$N8N_LOCAL/api/v1/healthz" > /dev/null 2>&1; then
  echo "✓ n8n reachable at $N8N_LOCAL"
  exit 0
fi

# Not reachable — print tunnel command
echo "✗ n8n NOT reachable — SSH tunnel may be closed."
echo ""
if [ -n "$VPS_SSH_HOST" ] && [ -n "$VPS_TUNNEL_PORTS" ]; then
  echo "Run: ssh $VPS_TUNNEL_PORTS $VPS_SSH_HOST"
else
  echo "Set VPS_SSH_HOST and VPS_TUNNEL_PORTS in .env, then run the SSH tunnel."
  echo "Example .env values:"
  echo "  VPS_SSH_HOST=root@45.79.125.184"
  echo "  VPS_TUNNEL_PORTS=-L 5678:localhost:5678 -L 5050:localhost:5050 -L 5432:localhost:5432"
fi
echo ""
echo "After opening the tunnel, re-run: /session-start"
exit 1
EOF
chmod +x scripts/session-startup.sh

#!/bin/bash
# Exports all n8n workflows to workflows/ directory.
# Output goes to disk — nothing enters Claude context.
# Usage: ./scripts/export-all-workflows.sh [project-root]
# Reads N8N_API_KEY and N8N_BASE_URL from .env.

set -e
PROJECT_ROOT="${1:-$(pwd)}"

# Load .env
if [ -f "$PROJECT_ROOT/.env" ]; then
  set -a; source "$PROJECT_ROOT/.env"; set +a
elif [ -f "$HOME/.claude/.env" ]; then
  set -a; source "$HOME/.claude/.env"; set +a
fi

: "${N8N_API_KEY:?N8N_API_KEY not set in .env}"
: "${N8N_BASE_URL:?N8N_BASE_URL not set in .env}"

WORKFLOWS_DIR="$PROJECT_ROOT/workflows"
mkdir -p "$WORKFLOWS_DIR"

# Fetch all workflow IDs (API response to scratch, only IDs extracted)
SCRATCH="/tmp/claude-scratch"
mkdir -p "$SCRATCH"

curl -sf -H "X-N8N-API-KEY: $N8N_API_KEY" \
  "${N8N_BASE_URL}/workflows?limit=250" > "$SCRATCH/wf-list.json"

IDS=$(jq -r '.data[].id' "$SCRATCH/wf-list.json")
COUNT=0

for id in $IDS; do
  curl -sf -H "X-N8N-API-KEY: $N8N_API_KEY" \
    "${N8N_BASE_URL}/workflows/${id}" > "$WORKFLOWS_DIR/${id}.json"
  COUNT=$((COUNT + 1))
done

rm -f "$SCRATCH/wf-list.json"
echo "Exported $COUNT workflows to workflows/"
EOF
chmod +x scripts/export-all-workflows.sh

## Task 6: Write build-dependency-map.sh

**Files:**
- Create: `n8n-whatsapp-methodology/scripts/build-dependency-map.sh`

This script parses `workflows/*.json` for `n8n-nodes-base.executeWorkflow` nodes and builds a Mermaid + JSON dependency map.

> **Note on n8n node structure:** In modern n8n, the Execute Workflow node stores the target workflow ID in `parameters.workflowId` as either a plain string or a resource locator object `{"__rl": true, "value": "<id>", "mode": "id"}`. The script handles both patterns. If the generated map has no edges, inspect a workflow JSON to check the exact `parameters` structure: `jq '.nodes[] | select(.type | contains("executeWorkflow"))' workflows/<id>.json`

- [ ] **Step 1: Write the script**

```bash
cat > scripts/build-dependency-map.sh << 'EOF'
#!/bin/bash
# Builds dependency-map.md from exported workflow JSONs.
# Usage: ./scripts/build-dependency-map.sh [workflows-dir] [project-root]
# Requires: jq

set -e
WORKFLOWS_DIR="${1:-workflows}"
PROJECT_ROOT="${2:-$(pwd)}"
OUTPUT="$PROJECT_ROOT/dependency-map.md"

if [ ! -d "$PROJECT_ROOT/$WORKFLOWS_DIR" ]; then
  echo "Error: $WORKFLOWS_DIR not found in $PROJECT_ROOT"
  echo "Run export-all-workflows.sh first"
  exit 1
fi

command -v jq >/dev/null 2>&1 || { echo "Error: jq is required"; exit 1; }

# Build name lookup: id -> name
declare -A WF_NAMES
for f in "$PROJECT_ROOT/$WORKFLOWS_DIR"/*.json; do
  id=$(jq -r '.id // empty' "$f" 2>/dev/null)
  name=$(jq -r '.name // empty' "$f" 2>/dev/null)
  [ -n "$id" ] && WF_NAMES["$id"]="$name"
done

# Build edge list
declare -A EDGES  # "source_id|target_id" -> 1
declare -A CALLERS  # source_id -> space-separated target IDs

for f in "$PROJECT_ROOT/$WORKFLOWS_DIR"/*.json; do
  source_id=$(jq -r '.id // empty' "$f" 2>/dev/null)
  [ -z "$source_id" ] && continue

  # Extract target IDs — handles plain string and resource locator patterns
  targets=$(jq -r '
    .nodes[]?
    | select(.type == "n8n-nodes-base.executeWorkflow")
    | .parameters.workflowId
    | if type == "object" then .value else . end
    | select(. != null and . != "")
  ' "$f" 2>/dev/null || true)

  for target_id in $targets; do
    EDGES["${source_id}|${target_id}"]=1
    CALLERS["$source_id"]+="$target_id "
  done
done

# Write output
{
echo "# Workflow Dependency Map"
echo "Generated: $(date '+%Y-%m-%d %H:%M')"
echo ""
echo "## Diagram"
echo '```mermaid'
echo 'graph TD'

if [ ${#EDGES[@]} -eq 0 ]; then
  echo '  note["No execute-workflow edges found — check node type in your workflow JSONs"]'
else
  for edge in "${!EDGES[@]}"; do
    src="${edge%%|*}"
    tgt="${edge##*|}"
    src_name="${WF_NAMES[$src]:-$src}"
    tgt_name="${WF_NAMES[$tgt]:-$tgt}"
    # Sanitize for Mermaid node IDs
    src_id=$(echo "$src" | tr -dc '[:alnum:]')
    tgt_id=$(echo "$tgt" | tr -dc '[:alnum:]')
    echo "  ${src_id}[\"${src_name}\"] --> ${tgt_id}[\"${tgt_name}\"]"
  done
fi

echo '```'
echo ""
echo "## Machine-Readable"
echo '```json'
echo "{"

first=true
for source_id in "${!CALLERS[@]}"; do
  [ "$first" = false ] && echo ","
  targets="${CALLERS[$source_id]}"
  # Build JSON array of target IDs
  target_array=$(echo "$targets" | tr ' ' '\n' | grep -v '^$' \
    | jq -R . | jq -s '.' 2>/dev/null)
  printf '  "%s": { "calls": %s }' "$source_id" "$target_array"
  first=false
done

echo ""
echo "}"
echo '```'
} > "$OUTPUT"

EDGE_COUNT=${#EDGES[@]}
echo "Dependency map written to dependency-map.md ($EDGE_COUNT edges found)"
EOF
chmod +x scripts/build-dependency-map.sh
```

- [ ] **Step 1: Write session-start.sh hook**

```bash
cat > hooks/session-start.sh << 'EOF'
#!/bin/bash
# Session-start hook — injected automatically at session open.
# Outputs compact project state summary to Claude context.
# Run from project root (Claude Code sets CWD to project root).

PROJECT_ROOT="$(pwd)"
REGISTRY="$PROJECT_ROOT/workflow-registry.md"
METHODOLOGY_DIR="$PROJECT_ROOT/.methodology"

echo "=== Methodology Plugin: Session Start ==="
echo ""

# 1. Connectivity check
if curl -sf --max-time 2 "http://localhost:5678/api/v1/healthz" > /dev/null 2>&1; then
  echo "n8n: ✓ reachable"
else
  echo "n8n: ✗ NOT reachable — SSH tunnel likely closed"
fi

# 2. Registry WIP summary (grep only — no full file in context)
if [ -f "$REGISTRY" ]; then
  echo ""
  echo "--- Workflow Registry: WIP Items ---"
  grep -A 50 "WIP\|In Progress\|🔴\|🟠\|TODO\|NEXT" "$REGISTRY" 2>/dev/null \
    | head -30 || echo "(No WIP section found in registry)"
fi

# 3. Stale workflows check
if [ -d "$PROJECT_ROOT/workflows" ]; then
  NEWEST_WF=$(find "$PROJECT_ROOT/workflows" -name "*.json" \
    -newer "$PROJECT_ROOT/dependency-map.md" 2>/dev/null | head -1)
  if [ -n "$NEWEST_WF" ]; then
    echo ""
    echo "⚠ dependency-map.md may be stale — workflow JSONs are newer."
    echo "  Run: scripts/export-all-workflows.sh && scripts/build-dependency-map.sh"
  fi
fi

# 4. Latest handoff summary
if [ -d "$METHODOLOGY_DIR" ]; then
  LATEST_HANDOFF=$(ls -t "$METHODOLOGY_DIR"/handoff-*.md 2>/dev/null | head -1)
  if [ -n "$LATEST_HANDOFF" ]; then
    echo ""
    echo "--- Last Session Handoff: $(basename "$LATEST_HANDOFF") ---"
    cat "$LATEST_HANDOFF"
  fi
fi

echo ""
echo "========================================="
EOF
chmod +x hooks/session-start.sh
```
