## Validation rule (P2-2.2 step 6)

For each (id, column) pair above, post-migration:
```sql
SELECT id, <col>::text AS after_text,
       (<col> AT TIME ZONE 'Asia/Kolkata')::text AS as_ist
  FROM chinmay_astro.<table> WHERE id = <id>;
```
- `as_ist` must match `before_text` byte-for-byte.
- `after_text` (which is timestamptz rendered in session TZ = UTC) must match `expected_after_text` byte-for-byte.

NULL rows: no validation needed (NULLs survive the conversion as NULLs).
